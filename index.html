How this works

No store, no account, no middleman

Files are hosted on GitHub Releases and linked from here. That keeps downloads free and permanent, and it means you can always check what you are installing.

Direct downloads

Every link goes straight to the file on GitHub Releases. No redirect pages, no waiting timers, no sign-up.

Checksums published

Where a file matters, a .sha256 sits beside it so you can confirm the download arrived intact.

Versioned releases

Each build is tagged with a version and a date. Older versions stay available instead of disappearing.

Small updates

Delta patches update an older version without re-downloading the whole file, when a full build would be wasteful.

Source available

Projects are public on GitHub. You can read the code, clone it, build it yourself or open an issue.

Free to download

No price, no subscription, no account. Download the file and use it.
