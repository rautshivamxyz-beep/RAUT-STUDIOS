Installing and using downloads

Almost everything here is either an Android APK or a Windows build, and neither comes from an app store. It takes a few minutes and needs no developer tools.

Android apps

APK · sideload
  1. Download the .apk from the files page.
  2. Open the downloaded file. If Android warns you, allow installs from your browser or file manager.
  3. Finish the install and open the app. Anything it needs from you is explained inside the app.
  4. To update later, download the newer APK and install it over the old one — your data stays.

Windows builds

ZIP · extract and run
  1. Download the .zip and extract it to a normal writable folder, such as Documents. Not Program Files.
  2. Open the extracted folder and look for a start file — usually .bat or .exe.
  3. Double-click it. Anything the app needs is either bundled or described in its README.
  4. To update, extract the newer build over the old folder, or replace it.
Other file types

Documents, archives and patches

Documents

PDFs and notes need nothing installed. Open them in any viewer.

Archives

Extract the ZIP first, then read the README inside. Running from inside a compressed folder breaks most apps.

Patches

A delta from an older version. Only apply it if you have that exact version; otherwise take the full build.

Before you install

Check the download

Where a .sha256 is published, compare it with the file you downloaded. Matching strings mean the file arrived complete.

SystemCommand
Windows (PowerShell)Get-FileHash .\your-file.zip -Algorithm SHA256
Linux / macOSsha256sum your-file.zip
Android (Termux)sha256sum your-file.apk
When something goes wrong

Troubleshooting

Android says the APK is unsafe or blocks the install
Android blocks files from browsers by default. Open Settings → Apps → Special access → Install unknown apps, pick the app you downloaded with (Chrome, Files), and allow it. Then open the APK again. Play Protect may also warn you — choose "install anyway" if you trust the source.
The APK will not install at all
Most builds here target Android arm64. A device on a different architecture, or on an older Android version than the app supports, will refuse it. If you already have an older version installed with a different signature, uninstall it first.
A Windows build closes immediately
Extract the ZIP to a normal writable folder first — running from inside the compressed folder, or from a protected location such as Program Files, stops most apps from starting.
The download will not finish or is corrupt
Check the size against the number in the table. If it is short, download again — and compare the checksum where one is published. A partial download is the usual cause.
Which file do I actually need?
The files page lists every build with its description. Take the newest version for your platform; ignore patches unless you are updating a specific older version.
How do I update later?
Download the newer build from the files page and install or extract it over the old one. There is no auto-updater, because there is no store in the middle.

Still stuck?

Open an issue on the project's repository and say what happened — device, version, and what you saw.
