Reading the tags

What each label means

Not every row is an app. The tag tells you what kind of file it is before you download it.

App

An installable build: an Android APK, or a Windows ZIP you extract and run.

Checksum

A .sha256 file. Compare it with your download to prove nothing was corrupted or altered.

Patch

A delta from one version to another. Small, but only useful if you already have that exact older version.

Document

Readable material — a PDF, notes or a guide. Nothing to install.

Archive

A ZIP or similar bundle — assets, models or a whole project folder. Extract it, then read the included README.

Other

Anything that does not fit the labels above. The description says what it is.
