How releases work

Version numbers and where builds live

Published builds

A version tag means the build exists and can be downloaded. The number on the card is the current release.

Source only

Where there is no release yet, the card links to the repository. You can build it yourself from there.

Updates

There is no app-store updater. New builds appear on the releases page, and delta patches are listed on the files page.
